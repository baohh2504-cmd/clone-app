## Reference Analysis
- **Background:** Deep dark (`#050505`) với họa tiết Grid mờ (`rgba(255,255,255,0.05)`).
- **Cards:** Background đen mờ, Border gradient hoặc colored border trái.
- **Typography:** Font hiện đại (Inter), tiêu đề nổi bật.
- **Pro Tips Section:** Layout grid 2 cột, mỗi card một màu nhấn riêng (Cyberpunk colors).
