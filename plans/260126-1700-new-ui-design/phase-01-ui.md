Status: ⬜ Pending

## Objective
Thiết lập nền tảng giao diện mới (Background, Colors, Fonts) và áp dụng cho màn hình chính (Dashboard).

## Requirements
- [ ] **Background:** Tạo hiệu ứng Grid Background (dùng CSS gradient hoặc SVG).
- [ ] **Header:** Redesign header trong suốt (glassmorphism) hoặc tối giản.
- [ ] **Dashboard Cards:**
    - [ ] Áp dụng style mới cho các card "Clone App".
    - [ ] Border sáng khi hover (Neon effect).
- [ ] **Sidebar:** Tinh chỉnh màu sắc cho đồng bộ với theme mới.

## Implementation Steps
1. [ ] **Update Tailwind Config:** Thêm màu mới (Cyber Black, Neon Blue, Neon Green, etc.).
2. [ ] **Global CSS:** Thêm class `.bg-grid-pattern` vào `index.html`.
3. [ ] **Refactor Dashboard:** Sửa layout và card styles trong `index.html` và `renderer.js` (phần render card).
4. [ ] **Pro Tips Area (Optional):** Nếu user muốn thêm phần "Pro Tips" như ảnh mẫu.
