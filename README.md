# Clone App ULTRA

## Overview
A desktop application for managing multiple application clones with isolated profiles.
Built with Electron (Frontend) and Python (Backend).

## Project Structure
- `source/ui`: Electron frontend (JS/HTML/CSS)
- `source/launcher`: Python backend launcher
- `.brain/`: Antigravity context memory

## Development
- **Status**: In Development
- **Current Focus**: Profile Storage Path Auto-fill
